# GrowthLab: Self Development for Job Seeker

Media pembelajaran interaktif berbasis website — Kelompok 8, Teknologi Pendidikan FIP UNJ.

Halaman utama: `index.html`. Situs ini dipublikasikan lewat GitHub Pages.

## Versi offline

Folder [`offline/`](offline/) berisi paket yang bisa dipakai tanpa internet:

- `GrowthLab_offline.html` — satu file, cukup dibuka di browser.
- `GrowthLab_offline.zip` — file HTML yang sama dalam bentuk ZIP.
- `GrowthLab_SCORM12.zip` — paket SCORM 1.2 untuk diunggah ke LMS (Moodle, dll.).

Unduh langsung: [HTML](https://akirasakamiyo.github.io/GrowthLab/offline/GrowthLab_offline.html) ·
[ZIP](https://akirasakamiyo.github.io/GrowthLab/offline/GrowthLab_offline.zip) ·
[SCORM](https://akirasakamiyo.github.io/GrowthLab/offline/GrowthLab_SCORM12.zip)
